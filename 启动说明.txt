========================================
  三角独眼怪桌宠 V2 · 启动说明
========================================

【这是什么】
  用 C# WinForms（.NET Framework 4.x）从零自研的全新 Windows 桌宠程序，
  完全替代旧版 Shimeji-ee 引擎方案，规避了旧版全部已知问题
  （单击飞起、交互失效、拖拽失效、静默退出等）。

【如何启动】
  1. 双击本目录下的 三角独眼怪桌宠.exe 即可运行。
  2. 想同时养多只：再双击一次 exe，就是新的一只（每只独立运行）。
  3. 桌宠会出现在屏幕底部，无边框、透明背景、始终置顶。

【如何退出】
  - 右键点击桌宠 -> 选择“退出桌宠”。
  - 想全部退出：把每只桌宠都右键退出，或在任务管理器结束对应进程。

【交互功能】
  单击：随机贴地小反应（眨眼 / 歪头 / 点头 / 摇摆 / 缩身 / 环顾 / 伸懒腰），
         全部使用贴地帧，不会飞起。
  双击：恐惧发抖（颤抖帧循环后缩身收尾）。
  三击：贴地横跑逃跑（向远离鼠标的方向跑，跑一会儿停下）。
  拖拽：按住角色任意位置（主体或边缘）拖动，桌宠跟随鼠标移动；
         松手直接停在原地，不会扔出、不会飞起。
  悬停：鼠标悬停在桌宠上，会歪头好奇看向你。
  待机：不定时眨眼、歪头、点头、摇摆、环顾、伸懒腰等小动作；
         偶尔会沿屏幕底部左右溜达几步。
  贴地：被拖到高处松手后，会自然缓慢落回屏幕底部。

【常见问题】
  - 桌宠不见了：可能在屏幕边缘/底部被遮挡，多按几次三击或右键退出后重新双击。
  - 想修改行为/帧：改 Program.cs 后重新编译即可（用系统自带的 csc：
    C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe）。
  - 帧图缺失：程序有兜底逻辑，缺帧不会崩溃（会用相邻帧补位）。
  - 需要 Java 吗？不需要。本程序纯 C# 运行，只要 Windows 自带 .NET 4.x 即可。
